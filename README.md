# Green Haven

موقع متجر نباتات (HTML / CSS / JavaScript) يحتوي على الصفحات: الرئيسية، المتجر، العناية بالنباتات، السلة، الدفع، وتأكيد الطلب.

## التشغيل
افتح `index.html` في المتصفح.

## الملفات
- `index.html`, `shop.html`, `care.html`, `cart.html`, `checkout.html`, `confirmation.html` — الصفحات
- `style.css`, `script.js` — التنسيق والسلوك
- `docs/` — ملف التقرير (PDF)
